⚠️ Apps Script Belum Dikonfigurasi

Data hanya tersimpan di browser (lokal). Untuk menyimpan ke server & Google Sheets:
1. Deploy appsscript_v8.gs sebagai Web App di script.google.com
2. Copy URL hasil deploy
3. Buka file HTML ini dengan Notepad → cari PASTE_URL_APPS_SCRIPT_DISINI → ganti dengan URL tersebut → upload ulang ke GitHub

💡 Sementara ini, Anda tetap bisa mengelola data di admin panel dan data tersimpan di browser. Refresh halaman = data hilang jika belum tersimpan ke server.
